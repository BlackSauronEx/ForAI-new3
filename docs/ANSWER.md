# Раунд C1 готов: вкладка «Кнопки и уведомления» работает

## Сначала — ответ на ваш вопрос про вкладки

Да, вы поняли верно, и это штатный для WordPress подход (так же устроены настройки WooCommerce):

- **Одна страница, несколько адресов.** Все вкладки живут на одном экране `admin.php?page=rvn-compare`, а текущая вкладка задаётся параметром URL: `?tab=general`, `?tab=buttons`, `?tab=page`, `?tab=table`, `?tab=system`. Переход между вкладками — обычный переход по ссылке (свой адрес, работает кнопка «Назад», вкладку можно отправить ссылкой).
- **PHP управляет вкладками.** Класс `Settings_Page` читает параметр, проверяет права и выводит содержимое нужной вкладки. Каждая вкладка — свои ключи настроек, своё сохранение и свой сброс: сброс никогда не задевает соседние вкладки.
- **React — только там, где нужна интерактивность.** Сейчас это две вкладки: «Основное» (раунды A/B) и «Кнопки и уведомления» (раунд C). Остальные три («Страница», «Поля сравнения», «Состояние системы») — обычные PHP-формы без React, работают без JavaScript и проверены с 0.3.x. Бандл подключается только на React-вкладках.
- **Небольшая поправка:** внутри вкладки «Основное» в раунде A я оставил тестовую «одновкладочную» панель React. С этого раунда она заменена: React рисует ровно ту панель, которой соответствует открытая вкладка (`activeTab` приходит из PHP), а единственной навигацией остаются штатные вкладки страницы.

## Что сделано в раунде C1 (кнопки)

- **Новая вкладка «Кнопки и уведомления»** (`?tab=buttons`), пятая на странице настроек, на том же React.
- **Позиция кнопки**: карточки (9 позиций, включая «Скрыта — только шорткод») и страница товара.
- **Режимы**: 6 режимов для компьютера и телефона отдельно; для телефона страницы товара — «как на компьютере».
- **Тексты** обоих состояний кнопки (пустое поле = встроенный перевод).
- **Повторный клик** (`second_click_action`): по умолчанию убрать товар из сравнения; можно открыть страницу сравнения. Если страницы нет — безопасный откат к удалению.
- **Иконка**: встроенный набор / свой emoji (один символ) / без иконки. Пустой emoji откатывается к встроенному набору, а режим «без иконки» в режиме «только иконка» показывает текст, чтобы кнопка не осталась пустой.
- **«Где показывать» (полный вариант B1)**: 6 контекстов WooCommerce для карточек — магазин, категории и теги, поиск, главная, похожие товары, корзина (корзина выключена по умолчанию, как в старом ТЗ) — плюс ограничения по URL: режим «скрывать на указанных» / «показывать только на указанных» и маски со звёздочкой `*` (например, `sale/*`). Маска сопоставляется один раз за запрос. Шорткод с явным ID, как и исключения, этими правилами не ограничивается.
- **Витрина подчиняется настройкам**: повторный клик, контексты и маски работают на реальных страницах; `uninstall.php` не трогался (все ключи лежат внутри опции `rvn_compare_settings`).
