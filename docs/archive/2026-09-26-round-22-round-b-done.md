# Раунд B готов: вкладка «Основное» работает и сохраняет настройки

## Коротко

- **Вкладка «Основное» стала рабочей.** Она правит и сохраняет настоящие настройки: общий лимит и лимит на вкладку, правило сравнения, игнорируемые категории, название вкладки «Прочее», исключения товаров и категорий (у каждого — отдельные переключатели «карточки товаров» и «страница товара»), акцентный цвет, отступы сверху и снизу, а также кнопки «Сохранить» и «Сбросить эту вкладку».
- **Поиск товаров для исключений работает через сервер**: вводите минимум два символа, запрос уходит в WordPress, список предлагает товары по названию или артикулу (не больше 10).
- **Сброс касается только этой вкладки** и спрашивает подтверждение: остальные вкладки не затрагиваются.
- **Проверки зелёные.** Уровень 0 — 5/5. Уровень 1 на стенде `main` — 12/12 за 57 секунд, в том числе браузерная проверка админки 18/18 (полный цикл: изменение → сохранение → перезагрузка → поиск → добавление в исключения → сброс) и Plugin Check 0 ошибок / 0 предупреждений. Стенд в конце раунда остановлен.
- **Новых ключей настроек не появилось**, версия не поднималась (в заголовках по-прежнему 0.4.1), витрина магазина не менялась.

## Два дефекта, которые нашлись и исправлены в раунде

1. **Сохранение отвечало ошибкой 403.** Функции WordPress, которые добавляют nonce к ссылке, возвращают её в HTML-виде (`&amp;`). В JSON-данных браузер отправлял nonce в параметре с искажённым именем, и проверка не проходила. Теперь ссылка собирается вручную — сохранение отвечает 200 и возвращает очищенные значения.
2. **Автоматическая проверка не находила поле поиска.** Метка `data-testid` у компонента WordPress не всегда доходит до самого поля ввода. Теперь каждое поле обёрнуто в свой контейнер с меткой, и проверка ищет поле внутри него.
